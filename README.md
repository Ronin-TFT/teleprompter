# 口播提词器

给录口播、网课、直播用的 macOS 悬浮提词器。半透明窗口贴在摄像头下方，按你的语速平滑滚动，录屏和直播时自动隐藏。

## 功能

- **悬浮提词窗**：半透明、始终置顶、可拖动和调整大小，不会抢走正在录制的软件的焦点；全屏应用上方也能显示。
- **录屏时隐藏**：开启后，屏幕录制、会议共享画面里看不到提词器（部分录屏软件可能不遵守，请先试录确认）。
- **按语速滚动**：以“字/分钟”设置语速，显示预计时长和剩余时间；中途可加速、减速、回退、前进、滚轮微调。
- **阅读线与高亮**：黄色阅读线标出该读的位置，当前句高亮，已读的句子变暗。
- **稿子格式**：`#` 开头的行显示为段落标题；单独一行写 `[停顿]` 会显示停顿提示。
- **镜像**：左右镜像（提词玻璃）和上下翻转。
- **开始倒计时**、字号、行宽、阅读线位置、背景透明度、对齐方式。
- **记住进度**：每份稿子单独记住读到的位置，下次打开接着读。
- **导入稿子**：支持 UTF-8、UTF-16、GB18030 编码的 txt / md。

## 全局快捷键（在其他软件中也可用）

| 快捷键 | 作用 |
|---|---|
| `⌥⌘P` | 开始 / 暂停 |
| `⌥⌘=` / `⌥⌘-` | 加速 / 减速 |
| `⌥⌘[` / `⌥⌘]` | 回退 / 前进几行 |
| `⌥⌘R` | 从头开始 |
| `⌥⌘T` | 显示 / 隐藏提词器 |

提词窗内还可以用：空格开始/暂停，方向键调整，`+` / `-` 调字号，Esc 暂停。

## 安装与构建

要求 macOS 13+。需要 Xcode Command Line Tools（`xcode-select --install`）。

```sh
./build_dmg.sh
open dist/Teleprompter.dmg
```

生成的是 Apple Silicon + Intel 通用版，使用临时签名。首次打开如被拦截，在“系统设置 → 隐私与安全性”中点“仍要打开”。
全局快捷键不需要辅助功能权限。

## 测试

```sh
# 网页界面（编辑与提词两种模式），需要 Node.js
npm install && npx playwright install chromium
npm test

# 原生部分
mkdir -p build
clang -fobjc-arc -I mac tests/mac_test.m mac/TPSupport.m mac/TPHotkeys.m -framework Cocoa -framework Carbon -o build/mac-test && build/mac-test
```

## 代码结构

| 路径 | 作用 |
|---|---|
| `web/app.html` | 界面：`#editor` 为稿子窗口，`#prompter` 为提词窗（滚动、高亮、倒计时） |
| `mac/TPAppDelegate.m` | 两个窗口、消息转发、窗口透明度与录屏隐藏、导入 |
| `mac/TPHotkeys.m` | 全局快捷键 |
| `mac/TPSupport.m` | 文本读取、状态保存、消息编码 |
| `tools/make_icon.m` | 生成应用图标 |
| `tests/` | 网页自动测试与原生测试 |
